# Tareas de Cómputo Emergente

Repositorio que recopila las prácticas, tareas y modelos implementados durante el curso de **Cómputo Emergente**. El objetivo de estos proyectos es estudiar, modelar y simular sistemas complejos, heurísticas de optimización bioinspiradas y arquitecturas fundamentales de aprendizaje automático.

---

## Estructura del Repositorio

El repositorio se divide en tres módulos temáticos principales:

```text
Tareas-Computo-Emergente/
├── Algoritmos Geneticos/
│   └── Implementaciones de optimización heurística y búsqueda evolutiva
├── Automatas Celulares/
│   └── Modelado de dinámicas discretas espaciotemporales (incluyendo modelos de agentes/ISAAC)
└── Redes Neuronales/
    └── Arquitecturas clásicas y modernas (Perceptrón Multicapa, Hopfield, SOM de Kohonen, RBF)
